Gere uma cópia de segurança completa dos dados do sistema (pacientes, destinos, veículos, agendamentos, usuários e trilha de auditoria). O arquivo é baixado compactado (.json.gz) para o seu computador.

{% csrf_token %}

Guarde o arquivo em local seguro (de preferência fora do servidor). Cada geração de backup fica registrada na trilha de auditoria.

Como restaurar

A restauração é feita pela equipe de TI, no servidor, a partir do arquivo gerado:

.venv\Scripts\python.exe manage.py restore caminho\do\arquivo.json.gz

A restauração sobrescreve os dados atuais. Faça um backup antes e execute em ambiente controlado.

Recomendações

  • Faça backup com frequência (diário ou a cada expediente).
  • Mantenha cópias em mais de um local (pendrive/rede), fora do servidor.
  • Em produção com PostgreSQL, este backup lógico complementa — não substitui — o pg_dump feito pela TI (ver manual de backup).
