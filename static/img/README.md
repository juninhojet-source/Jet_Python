# Imagens estáticas

Coloque aqui o **brasão oficial** do Município de Barão de Cocais com o nome:

    brasao.png

O cabeçalho (`templates/base.html`) e o favicon já apontam para
`static/img/brasao.png`. Enquanto o arquivo não existir, o cabeçalho oculta a
imagem automaticamente (sem imagem quebrada).

Formato recomendado: PNG com fundo transparente ou branco, altura ~200px.
